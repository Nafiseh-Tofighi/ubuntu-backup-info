Ubuntu Backup

A personal backup tool operated by Nafiseh Tofighi for her own Ubuntu computer and Google Drive account.

What it does

The tool uses rclone to copy files from Desktop and Downloads to the account owner’s Google Drive, after an explicit upload confirmation. Files larger than 1,000,000,000 bytes are skipped and listed in a local report. Unchanged files are not uploaded again, and previous versions of replaced files are retained.

Backup files remain in the owner’s Google Drive and are accessible there as ordinary files. This website hosts information only; it does not host backups or authentication credentials.

Google access

The application requests the Google Drive drive.file permission to create and manage its backup files. It is intended for personal use, not as a public backup service.
